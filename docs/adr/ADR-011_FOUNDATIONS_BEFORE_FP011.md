# ADR-011 — Activar fundamentos antes de FP-011

- **Estado:** Accepted
- **Fecha:** 2026-08-05

## Contexto

FP-011 inicia una nueva etapa con formularios, ubicación y textos visibles.
Continuar sin i18n, accesibilidad, temas y arquitectura territorial generaría
deuda distribuida en muchas pantallas.

## Decisión

Antes de finalizar la interfaz de FP-011 se activan:

- FD-001, arquitectura territorial y geoespacial;
- FD-002, i18n, accesibilidad y temas;
- FP-006 como trabajo transversal real.

## Consecuencias

- pausa breve;
- menos retrabajo;
- FP-011 nace sobre contratos estables;
- no se exige implementar todas las capacidades futuras.
