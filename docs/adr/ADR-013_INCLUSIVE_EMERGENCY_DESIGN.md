# ADR-013 — Diseño inclusivo para flujos de urgencia

- **Estado:** Accepted
- **Fecha:** 2026-08-05

## Contexto

WCAG no cubre por sí sola todos los contextos de estrés, baja alfabetización,
dispositivos limitados o carga cognitiva presentes al perder un animal.

## Decisión

Los flujos críticos aplicarán diseño inclusivo además de conformidad técnica:

- reducción de decisiones;
- lenguaje claro;
- recuperación de errores;
- borradores;
- acciones multimodales;
- uso con una mano;
- rendimiento;
- pruebas bajo estrés.

## Consecuencias

- mayor trabajo de diseño y prueba;
- menos abandono;
- menos errores;
- mejor experiencia para toda la población.
