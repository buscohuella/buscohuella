# 🐾 PET_DOMAIN

> Primera base del dominio Pet. **Release 1 (borrador)**.

## Objetivo
La entidad `Pet` representa la identidad digital permanente de una mascota dentro de BuscoHuella.

## Principios
- Una mascota no es un reporte.
- Una mascota puede tener múltiples reportes durante su vida.
- La identidad permanece aunque cambie su estado.
