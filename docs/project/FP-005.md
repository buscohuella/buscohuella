# FP-005 — Librerías e integración web del dominio Pet

## Mejoras UX posteriores a la prueba manual

- [x] Confirmación visible tras registrar una mascota.
- [x] Confirmación visible tras archivar.
- [x] Acción segura de archivado desde el detalle.
- [x] Confirmación antes de archivar.
- [x] Conservación del historial y posibilidad futura de restauración.
- [ ] Eliminación definitiva en zona de peligro.
- [ ] Restauración de mascotas archivadas.
- [ ] Catálogo de razas y cruces.

## Decisión sobre eliminación

En esta fase se ofrece **archivado**, no borrado definitivo.

Motivos:

- conserva reportes y relaciones futuras;
- evita eliminaciones accidentales;
- permite restauración;
- mejora trazabilidad y soporte;
- protege la integridad del dominio.

La eliminación definitiva se añadirá en una zona de peligro con confirmación
reforzada y reglas específicas de conservación de datos.

## Razas y cruces

La mejora se implementará como bloque separado con catálogo normalizado:

- búsqueda incremental;
- «No conozco la raza»;
- «Mestizo / mezcla desconocida»;
- raza principal;
- segunda raza opcional;
- filtrado por especie;
- texto libre controlado solo para casos no catalogados.
