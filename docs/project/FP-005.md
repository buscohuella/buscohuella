## Seguridad

- La aplicación usa la clave publicable y la sesión del usuario.
- El repositorio no utiliza `service_role`.
- `listOwnPets()` depende de RLS para limitar las filas al propietario.
- La pantalla no recibe ni expone `owner_id`.
- Los errores de infraestructura no se muestran directamente al usuario.
