## Incidencias resueltas

### Zod 4 y esquemas refinados

La primera implementación intentaba ejecutar:

```ts
createPetSchema.partial()
```

sobre un esquema que ya contenía `superRefine()`.

Zod 4 no permite derivar `partial()` de objetos refinados.

Solución:

```text
Objeto base sin refinamientos
├── Create schema + superRefine
└── Partial schema + superRefine
```

La decisión queda documentada en `ADR-005`.
