## Decisiones

- El cliente Supabase se inyecta desde la aplicación.
- `pet-data` conoce Supabase; `pet-domain` no.
- La protección de propiedad sigue dependiendo de RLS.
- Los tipos generados se versionan para detectar cambios de contrato.
- No se permite modificar `owner_id` desde los mapeadores de actualización.
