# FP-006 — Fundación i18n, accesibilidad y temas

## Estado

**Estado:** `In Progress — transversal`

FP-006 está activo y se aplica durante la migración de pantallas.

## Implementado

### Temas

- tema claro y oscuro;
- detección inicial del dispositivo;
- persistencia;
- prevención del parpadeo inicial;
- selector disponible con y sin sesión;
- tokens semánticos;
- reducción de movimiento.

### Accesibilidad y diseño inclusivo

- foco visible;
- tamaños táctiles;
- componentes semánticos;
- errores junto al campo;
- resumen de errores con enlaces;
- estados de carga;
- mensajes anunciables;
- información no basada únicamente en color;
- confirmaciones accesibles;
- navegación por teclado en diálogos;
- pruebas manuales en Auth.

### Autenticación migrada

- login;
- registro;
- confirmación;
- recuperación;
- nueva contraseña;
- contraste público;
- tema público;
- validación robusta de correo;
- política de contraseña visible y validada en servidor.

## Pendiente inmediato

### Infraestructura i18n mínima

La interfaz actual está redactada en español, pero todavía no dispone de una
capa i18n operativa. Antes de migrar Perfil se implementará:

- locale base `es`;
- preparación de `ca`;
- namespaces;
- función o hook de traducción;
- mensajes parametrizados;
- formatos con `Intl`;
- textos del Design System inyectables;
- política para evitar nuevos textos incrustados;
- estrategia de rutas sin prefijo para español.

### Migración progresiva

```text
i18n mínimo
→ Perfil
→ Mascotas
→ Reportes
→ catálogo
→ auditoría final
```

## Objetivo MVP

- español como locale base una vez instalada la infraestructura i18n;
- catalán antes del piloto ampliado;
- preparación de euskera, gallego e inglés;
- textos extraíbles;
- formatos regionales;
- componentes accesibles;
- WCAG 2.2 AA como objetivo;
- alternativa accesible a cualquier mapa.

## Revisión transversal por pantalla

Cada pantalla visible deberá revisar:

- traducciones;
- textos largos;
- teclado y foco;
- contraste;
- zoom;
- lectores de pantalla;
- reducción de movimiento;
- claro y oscuro;
- móvil;
- recuperación de errores;
- seguridad y privacidad;
- carga cognitiva y lenguaje claro.

## Relación con FD-003

FP-006 define los requisitos transversales. FD-003 los convierte en tokens,
componentes y patrones reutilizables.

FD-003 no podrá cerrarse hasta validar la integración mínima de FP-006.
