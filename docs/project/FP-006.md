# FP-006 — Fundación i18n, accesibilidad y temas

## Estado

**Estado:** `In Progress — transversal`

FP-006 deja de ser únicamente una intención documental. Se activa antes de
FP-011 para impedir que los nuevos flujos acumulen deuda transversal.

## Objetivo MVP

- infraestructura de traducción;
- español y catalán;
- preparación de euskera, gallego e inglés;
- textos extraíbles;
- formatos con `Intl`;
- componentes base accesibles;
- WCAG 2.2 AA como objetivo;
- tokens semánticos;
- tema claro, oscuro y sistema;
- alternativa accesible a cualquier mapa.

## Relación con Feature Packs

FP-006 no sustituye las pruebas de accesibilidad de cada pantalla.

Cada Feature Pack visible deberá:

- usar claves de traducción;
- validar teclado y foco;
- conservar contraste;
- admitir zoom;
- no depender del color;
- anunciar errores y cambios;
- respetar reducción de movimiento;
- funcionar en tema claro y oscuro.

## Criterio de avance

FP-011 puede desarrollar dominio y datos en paralelo, pero su interfaz final
depende de la infraestructura mínima de FP-006.

## Diseño inclusivo

FP-006 incluye diseño inclusivo además de accesibilidad técnica:

- reducción de carga cognitiva;
- lenguaje claro;
- recuperación de errores;
- uso en situaciones de estrés;
- una sola mano;
- conexiones lentas;
- dispositivos modestos;
- personas mayores y baja alfabetización digital.
