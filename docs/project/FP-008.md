## Reglas principales

- `KNOWN` exige raza principal.
- Una segunda raza exige mezcla.
- Las dos razas deben ser distintas.
- `MIXED_UNKNOWN` exige mezcla y no admite IDs.
- `UNKNOWN` no admite IDs.
- La base de datos valida que cada raza pertenezca a la especie.
- El servidor resuelve los nombres desde el catálogo; no confía en etiquetas enviadas por el cliente.
- Los datos legados se conservan hasta que el usuario los normalice o indique que no conoce la raza.

## Pruebas manuales de la entrega web

1. Registrar perro y escribir `Pas`.
2. Seleccionar Pastor alemán.
3. Marcar cruce y seleccionar una segunda raza.
4. Confirmar que no permite repetir la misma raza.
5. Registrar una mascota con raza desconocida.
6. Registrar una mezcla de razas desconocidas.
7. Cambiar la especie después de seleccionar una raza.
8. Editar una ficha antigua con texto legado.
9. Navegar por el formulario usando teclado.
10. Comprobar mensajes de error y confirmación.
