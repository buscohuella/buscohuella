# FP-008 — Catálogo de razas y cruces

## Objetivo

Sustituir progresivamente el campo de raza de texto libre por un catálogo normalizado y una experiencia de selección intuitiva.

Debe permitir:

- buscar escribiendo fragmentos como `Pas`;
- seleccionar una raza principal;
- añadir una segunda raza para cruces conocidos;
- indicar que la raza no se conoce;
- indicar mezcla de origen desconocido;
- conservar fichas antiguas sin pérdida;
- preparar filtros, analítica y matching futuro.

## Estados de conocimiento

```text
KNOWN
UNKNOWN
MIXED_UNKNOWN
```

- `KNOWN`: se conoce al menos la raza principal.
- `UNKNOWN`: no se conoce la raza.
- `MIXED_UNKNOWN`: se sabe que es mestiza, pero no las razas.

El selector deberá funcionar con teclado, anunciar resultados, permitir Escape, mantener foco visible y no depender únicamente del color.

## Fuera de alcance

## Criterios de aceptación

- `Pas` encuentra razas relevantes.
- Cambiar especie invalida razas incompatibles.
- La segunda raza exige mezcla.
- No se obliga a conocer la raza.
- Las fichas antiguas siguen siendo legibles.
- Typecheck, tests, lint y build pasan.
