## Reglas principales

- `KNOWN` exige raza principal.
- Una segunda raza exige mezcla.
- Las dos razas deben ser distintas.
- `MIXED_UNKNOWN` exige mezcla y no admite IDs.
- `UNKNOWN` no admite IDs.
- La base de datos valida que cada raza pertenezca a la especie.
