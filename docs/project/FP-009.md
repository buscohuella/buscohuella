# FP-009 — Fotografías de mascotas

## Objetivo

Permitir que una persona propietaria añada, consulte, ordene, marque como
principal y elimine fotografías de sus mascotas de forma segura.

La solución debe reutilizarse desde la web y la futura aplicación móvil.

## Estado actual

**Estado:** `Completed`

**Progreso:** 100 %

**Último commit funcional:** `165bd2b`

**Commits principales:**

- `de6314b` — subida y gestión completa de galería;
- `165bd2b` — reordenado accesible y procesamiento seguro.

FP-009 está implementado, validado y publicado. El módulo incluye subida

procesamiento WebP, eliminación de metadatos sensibles y compensación de
archivos huérfanos.
## Alcance MVP

- subida de una o varias imágenes;
- foto principal;
- listado ordenado;
- cambio de portada;
- eliminación con confirmación;

- validación de tamaño, firma y tipo;
- texto alternativo editable;
- estados de carga, éxito y error;
- comportamiento accesible con teclado;
- diseño responsive.

## Reglas

1. Solo el propietario puede gestionar fotografías.
2. Una mascota puede tener un máximo de 10 fotografías.
3. Solo puede existir una foto principal por mascota.
4. La primera fotografía se convierte en principal automáticamente.
5. Al eliminar la principal, la primera restante pasa a ser principal.
6. El orden se representa mediante `position` entre 0 y 9.
7. Storage y metadatos deben mantenerse coherentes.
8. El servidor valida la firma del archivo, no solo el MIME del navegador.
9. Las imágenes son privadas y se muestran mediante URL firmada.
10. Las fichas archivadas pueden consultar fotos, pero no modificarlas.

## Procesamiento seguro de imágenes

- orientación automática mediante metadatos EXIF;
- eliminación de EXIF, GPS y otros metadatos sensibles;
- redimensionado máximo a 2048 px;
- conversión a WebP;
- límite de 8 MB para el archivo de entrada;
- límites mínimos y máximos de dimensiones;
- límite de megapíxeles;
- rechazo de imágenes corruptas o con firma inválida;
- compensación automática si Storage acepta el archivo y falla la base de datos;
- documentación complementaria en `FP-009_IMAGE_SECURITY.md`.
