# FP-010 — Dominio y base de datos de reportes

## Objetivo

Definir e implementar el núcleo compartido para los casos de animales perdidos,
animales encontrados y avistamientos.

FP-010 no construye los formularios completos. Su responsabilidad es dejar
reglas, ciclo de vida, esquema, seguridad, contratos de dominio y acceso a
datos preparados para web, futura aplicación móvil e intranets profesionales.

## Principios

1. `pets` representa identidad permanente; un reporte representa una incidencia.
2. Una mascota puede tener varios reportes históricos, pero solo uno abierto de pérdida.
3. Un animal encontrado puede publicarse sin crear previamente una mascota.
4. La ubicación exacta nunca se expone públicamente por defecto.
5. El contacto público no revela datos personales sin consentimiento.
6. Los avistamientos no modifican directamente la ubicación principal del reporte.
7. Cerrar y resolver son operaciones explícitas y auditables.
8. No se elimina físicamente un caso desde la interfaz ordinaria.
9. Los códigos internos son estables y no contienen traducciones.
10. IA, matching automático y chat quedan fuera de FP-010.

## Seguridad y privacidad

- la ubicación exacta no aparece en `PublicReport`;
- la ubicación pública se mantiene separada y degradada;
- las tablas base no se exponen directamente al público anónimo;
- la proyección pública se obtiene mediante función controlada;
- el creador solo puede modificar sus propios reportes;
- los eventos auditables no admiten escritura directa desde el cliente;
- una mascota no puede tener dos reportes de pérdida abiertos;
- los datos de contacto solo se exponen con consentimiento explícito.

## Escalabilidad

La arquitectura permite reutilizar el mismo núcleo desde:

- web pública;
- aplicación móvil;
- intranet administrativa;
- paneles de protectoras;
- veterinarios;
- policía local;
- ayuntamientos;
- procesos automáticos y Edge Functions.

Los roles y membresías profesionales se incorporarán en Feature Packs futuros
sin sustituir las tablas ni las reglas actuales.
