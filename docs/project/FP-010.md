# FP-010 — Dominio y base de datos de reportes

## Objetivo

Definir e implementar el núcleo compartido para los casos de animales perdidos,
animales encontrados y avistamientos.

FP-010 no construye todavía los formularios completos. Su responsabilidad es
dejar reglas, ciclo de vida, esquema, seguridad, contratos de dominio y acceso
a datos preparados para web y futura aplicación móvil.

## Estado

**Estado:** `In Progress`

**Entrega actual:** Fundación documental y contractual.

## Alcance

- reportes de mascota perdida;
- reportes de animal encontrado;
- avistamientos asociados a un reporte;
- estados y transiciones;
- ubicación exacta privada y ubicación pública protegida;
- privacidad y contacto;
- evidencias y fotografías;
- resolución y cierre;
- auditoría mínima;
- RLS;
- dominio compartido;
- repositorio compartido.

## Principios

1. `pets` representa identidad permanente; un reporte representa una incidencia.
2. Una mascota puede tener varios reportes históricos, pero solo uno abierto de pérdida.
3. Un animal encontrado puede publicarse sin crear previamente una mascota.
4. La ubicación exacta nunca se expone públicamente por defecto.
5. El contacto público no revela datos personales sin consentimiento.
6. Los avistamientos no modifican directamente la ubicación principal del reporte.
7. Cerrar y resolver son operaciones explícitas y auditables.
8. No se elimina físicamente un caso desde la interfaz ordinaria.
9. Los códigos internos son estables y no contienen traducciones.
10. IA, matching automático y chat quedan fuera de FP-010.

## Criterios de aceptación

- No se mezclan estados temporales con la tabla `pets`.
- Solo el creador y procesos autorizados modifican un reporte.
- La ubicación exacta permanece privada.
- La proyección pública contiene únicamente información segura.
- Las transiciones inválidas se rechazan.
- Una mascota no puede tener dos reportes de pérdida abiertos.
- Los avistamientos quedan vinculados y auditados.
- El esquema permite mapa, notificaciones y resolución futura.
- Web y móvil pueden reutilizar dominio y repositorio.
