# @buscohuella/report-data

Capa compartida de acceso a datos del dominio de reportes.

Incluye:

- tipos Supabase;
- serialización segura de puntos geográficos;
- mapeadores SQL ↔ dominio;
- normalización de errores;
- repositorio de reportes;
- proyección pública;
- repositorio de avistamientos;
- metadatos de fotografías;
- eventos auditables.

No contiene componentes de interfaz ni expone ubicaciones exactas en los
modelos públicos.
