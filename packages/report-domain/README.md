# @buscohuella/report-domain

Paquete compartido del dominio de reportes de BuscoHuella.

Incluye:

- tipos y constantes;
- estados y transiciones;
- validación de reportes;
- validación de publicación;
- resolución y cierre;
- avistamientos;
- fotografías y reordenado;
- límites de seguridad.

Se reutilizará desde web, aplicación móvil y capa de datos.
